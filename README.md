# Italy Travel Guide 2026

Static HTML travel guide for Naples, Bari, and nearby areas.

## Deploy on GitHub Pages

1. Keep the guide as `index.html` in the repository root.
2. Push this folder to GitHub.
3. In GitHub, open Settings > Pages.
4. Set Source to `Deploy from a branch`.
5. Select branch `main` and folder `/root`.

After GitHub builds it, the site will be available at:

`https://swadhagupta15.github.io/Travel/`

## Future Agent Support

To add a live AI travel assistant, use a backend/serverless function for API calls. Do not put API keys directly in `index.html`.
